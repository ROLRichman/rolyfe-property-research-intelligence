Step 1

Property Intake

Local browser workspace

Research discipline

✓ Verify exact address and parcel against county or municipal records.
✓ Confirm the sale type, deadline, deposit, fees, and buyer terms from the official source.
✓ Check property type, permitted use, occupancy, access, and zoning independently.
✓ Keep source links and the date each important fact was checked.

Records are saved in this browser on this device using local storage. Export a backup regularly. This is not a cloud database and does not sync across devices.
